# 高质量捕获

捕获阶段的目标，是用最低成本保存未来判断所需的上下文，而不是完整复制信息。

## 最小捕获单元

每条记录包含来源、问题、一句话价值和预期用途。无法写出预期用途的内容，通常不需要立即进入正式知识库。

::: tip 推荐做法
先把内容放进统一收件箱，每周集中处理。不要在阅读过程中不断切换工具和设计分类。
:::

## 不同来源的处理方式

| 来源 | 优先保留 | 可以省略 |
| --- | --- | --- |
| 文章 | 论点、证据、限制 | 大段原文 |
| 会议 | 决策、负责人、时间 | 无结论的讨论过程 |
| 代码 | 场景、关键实现、验证方式 | 可由仓库恢复的完整文件 |
| 灵感 | 触发原因、假设、下一步 | 过早的完整方案 |
